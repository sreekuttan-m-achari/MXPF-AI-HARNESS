# Release notes — mxpf-ai-harness 0.1.0

**Date:** 2026-08-21  
**Tag:** `v0.1.0`  
**npm:** `mxpf-ai-harness@0.1.0`  
**GitHub:** https://github.com/sreekuttan-m-achari/MXPF-AI-HARNESS

## Summary

First shippable MaximProf AI harness SDK: a greenfield TypeScript agent loop with coding tools, MCP (stdio), headless permissions, session resume, and Anthropic + OpenAI-compatible model pipes — without depending on Cursor or Claude Agent SDKs.

Products keep Cursor and Claude as switchable runtimes; this package is the `mxpf` backend.

## What’s included

- Public API: `Harness`, `Run`, events, `supports()`, typed errors
- Built-ins: Read / Write / Edit / Bash / Glob / Grep
- MCP stdio host + Cursor-like server config map
- Permissions: bypass | allowlist | deny-by-default
- Model clients: Anthropic Messages, OpenAI Chat Completions (+ `baseURL` pipes)
- Session durability on disk
- Docs: README, CHANGELOG, design spec, implementation plan
