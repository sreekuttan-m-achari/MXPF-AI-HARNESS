# mxpf-ai-harness 0.2.0

Token and throughput optimizations for long sessions and multi-tool turns.

## Highlights

- Tool-result / Read / Bash output caps (defaults 32k / 100k / 32k)
- Optional extractive context compaction (`context.autoCompact` or `maxInputChars`)
- Parallel tool execution (default on)
- Anthropic prompt-cache `cache_control` hints when `throughput.promptCache` is on
- Configurable `model.maxOutputTokens`
- Compact session JSON on disk

## Upgrade

```bash
npm install mxpf-ai-harness@^0.2.0
```

Additive API only — existing `Harness.create` callers keep working. Enable compaction explicitly:

```ts
context: { autoCompact: true }
```

See [optimizations design](../superpowers/specs/2026-08-21-mxpf-harness-optimizations-design.md).
